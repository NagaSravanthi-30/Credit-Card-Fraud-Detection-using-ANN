 💳 Credit Card Fraud Detection using ANN

🎯 1. Project Overview

A deep learning-based web application that detects whether a credit card transaction is **Genuine or Fraudulent** using an **Artificial Neural Network (ANN)**. The system accepts transaction details and provides a fraud probability from **0–100%**.

✨ 2. Key Features

* 🔍 Fraud/Genuine transaction classification
* 📊 Fraud probability prediction
* ⚙️ Transaction data preprocessing
* 🖥️ User-friendly web interface
* ⚡ Fast prediction through the backend API

🛠️ 3. Technologies Used

* 🐍 **Python**
* 🧠 **TensorFlow**
* 📊 **Pandas & NumPy**
* 🚀 **FastAPI**
* ⚛️ **React**
* 🔗 **Git & GitHub**

 🔄 4. How It Works
👤 User Transaction Details
          ↓
🖥️ React Frontend
          ↓
🚀 FastAPI Backend
          ↓
⚙️ Data Preprocessing
          ↓
🧠 ANN Model
          ↓
📊 Fraud Probability
          ↓
✅ Genuine / 🚨 Fraud

## 🏆 5. Project Outcome

The system analyzes transaction information and generates a **fraud probability (0–100%)**, helping identify potentially fraudulent transactions through a simple and user-friendly web application.
